Depuis la création de l’entreprise « PALMES & COMPETITIONS » 20 000 palmes ont été produites en pré-imprégné.

360 pièces ont été considérées comme mauvaises et ont été écartées.

Ces dernières sont classées par type de défauts.
Repère du défaut Nature du défaut Nombre
A A Mauvaise cuisson 17
B B Reste de film 135
C C Déformation après démoulage 21
D D Non-respect du plan de drapage 58
E E Rupture de linéarité de fibre 65
F F Porosité excessive 19
G G Mauvais détourage 45
       
1.  Remplir le tableau suivant afin de réaliser un Paréto cumulé
Classer les problèmes dans l'ordre décroissant     
On classe les défauts par ordre décroissant.
Calculer le total des défauts    
On calcul le total des défauts:
total = 135 + 65 +58 +45 +21 +19 +17 = 360
Calculer le % des défauts    
On calcul le % de chaque défaut en arrondissant au plus prés (2 chiffres après la virgule)

Pour B = % défauts = (135 / 360) * 100 = 37.50

Pour E = % défauts = (65 / 360) * 100 = 18.06

Pour D = % défauts = (58 / 360) * 100 = 16.11

Pour G = % défauts = (45 / 360) * 100 = 12.50

Pour C = % défauts = (21 / 360) * 100 = 5.83

Pour F = % défauts = (19 / 360) * 100 = 5.28

Pour A = % défauts = (17 / 360) * 100 = 4.72
Calculer le % cumulé    
On calcul le % cumulé de chaque défaut en arrondissant au plus prés (2 chiffres après la virgule)

Pour B = % cumulé =  37.50

Pour E = % cumulé =  37.50 + 18.06 = 55.56

Pour D = % cumulé =  55.56 + 16.11 = 71.67

Pour G = % cumulé =  71.67 + 12.50 = 84.17

Pour C = % cumulé =  84.17 + 5.83 = 90.00

Pour F = % cumulé =  90.00 + 5.28 = 95.28

Pour A = % cumulé =  95.28 + 4.72 = 100.00
2.  Remplir le diagramme de Paréto cumulé et tracer la courbe du % cumulé
Tracer l'histogramme    
On trace l'histogramme de chaque défaut.
Tracer de la courbe    
On trace la courbe correspondant aux défauts.
